# 📊 Proyecto 2 — Análisis de Ventas

## 📌 Descripción

Este proyecto presenta un análisis exploratorio de datos (EDA) aplicado a un conjunto de datos de ventas.

El objetivo es analizar el comportamiento de las ventas, identificar los productos y ciudades con mejor desempeño, estudiar la rentabilidad y obtener información útil para la toma de decisiones.

## 🎯 Objetivos

- Analizar el comportamiento general de las ventas.
- Identificar los productos con mayor desempeño.
- Comparar las ventas entre diferentes ciudades.
- Analizar ingresos, costos y ganancias.
- Calcular indicadores de rentabilidad.
- Crear visualizaciones para facilitar la interpretación de los datos.
- Identificar hallazgos relevantes y oportunidades de mejora.

## 🛠️ Herramientas utilizadas

- 🐍 Python
- 🐼 Pandas
- 📊 Matplotlib
- 📈 Visualización de datos
- 📓 Jupyter Notebook

## 🔎 Proceso de análisis

1. Carga de los datos.
2. Exploración inicial del conjunto de datos.
3. Limpieza y preparación de la información.
4. Transformación de variables.
5. Análisis de ventas.
6. Análisis de ganancias y rentabilidad.
7. Agrupación y comparación de información.
8. Creación de visualizaciones.
9. Identificación de hallazgos.
10. Elaboración de conclusiones.

## 📈 Análisis realizado

Durante el proyecto se analizaron diferentes aspectos relacionados con el desempeño comercial:

- Ventas totales.
- Ganancia total.
- Margen de rentabilidad.
- Desempeño por producto.
- Desempeño por ciudad.
- Comparación de productos.
- Tendencias y patrones de ventas.

## 💡 Resultados y hallazgos

El análisis permite identificar patrones importantes en el comportamiento de las ventas y la rentabilidad.

Las visualizaciones facilitan la comparación entre productos y ciudades, permitiendo reconocer aquellos elementos que presentan un mejor desempeño y aquellos que requieren mayor atención.

## 📊 Visualizaciones

Se utilizaron gráficos y visualizaciones para representar los principales resultados del análisis y facilitar la interpretación de la información.

Entre las visualizaciones desarrolladas se encuentran:

- Gráficos de ventas por producto.
- Comparaciones de ventas por ciudad.
- Visualizaciones de ganancias.
- Análisis de tendencias.
- Gráficos comparativos.

## 📚 Principales aprendizajes

Este proyecto permitió fortalecer conocimientos en análisis exploratorio de datos, limpieza de información, transformación de variables, agrupación de datos y creación de visualizaciones utilizando Python y Pandas.

También permitió aplicar el análisis de datos a un contexto empresarial orientado a la toma de decisiones.
